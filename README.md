# Portfolio

Portfolio personnel en HTML/CSS/JS, hébergé gratuitement sur GitHub Pages.

🔗 En ligne : https://nblinpro.github.io/portfolio-projets/

## Développement local

Ouvrez simplement `index.html` dans un navigateur, ou lancez un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrez http://localhost:8000

## Personnalisation

- Contenu : modifiez le texte dans `index.html` (hero, à propos, projets, compétences, contact).
- Style : couleurs et mise en page dans `css/style.css` (variables `:root` en haut du fichier).
- Comportement : menu mobile et thème clair/sombre dans `js/script.js`.

## Déploiement

Le site se déploie automatiquement sur GitHub Pages à chaque push sur la branche `main`
(voir Settings → Pages du dépôt).
