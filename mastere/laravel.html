Déploiement Automatisé Laravel via Ansible

Documentation technique du projet d'automatisation : gestion de configuration, déploiement sécurisé via Ansible Vault, rôles modulaires et durcissement du serveur sur Rocky Linux 9.

Contexte

Architecture du projet

Un playbook Ansible unique orchestre le déploiement complet d'une application Laravel sur deux serveurs Rocky Linux 9 : un serveur base de données et un serveur web, avec gestion centralisée des secrets.

Stack technique

  • PHP 8.3 installé via le dépôt REMI
  • MySQL Server
  • Apache (httpd) avec VirtualHost généré en Jinja2
  • Composer, gestionnaire de dépendances PHP
  • Laravel, framework applicatif
  • SELinux et Firewalld pour le durcissement

Sécurité & secrets

  • Ansible Vault pour chiffrer les identifiants de base de données
  • Permissions 700 / 600 sur les dossiers group_vars
  • Contexte SELinux httpd_sys_rw_content_t sur storage, cache et .env
  • Firewalld : ouverture des seuls ports 80, 443 et 3306
  • Accès MySQL restreint à l'adresse IP du serveur web

2. Configuration racine

Fichier d'inventaire — hosts.ini

[web]
weblaravel ansible_host=192.168.80.167 ansible_user=innosys

[db]
bddlaravel ansible_host=192.168.80.168 ansible_user=innosys

Playbook principal — site.yml

---
- name: Déploiement Base de Données
  hosts: db
  become: yes
  roles:
    - database

- name: Déploiement Serveur Web
  hosts: web
  become: yes
  roles:
    - php
    - apache
    - composer
    - laravel
    - selinux
    - firewall

3. Variables & sécurité (Vault)

Configuration DB — group_vars/db/vault.yml

Création du coffre-fort : sudo ansible-vault create group_vars/db/vault.yml

# vault.yml
mysql_root_password: "RootPass123!"
laravel_db: "laravel_db"
laravel_user: "laravel_user"
laravel_password: "LaravelPass123!"

Configuration Web — group_vars/web/

Création du coffre-fort : sudo ansible-vault create group_vars/web/vault.yml

# vault.yml
db_password: "LaravelPass123!"
db_name: "laravel_db"
db_user: "laravel_user"

# vars.yml
app_path: /var/www/laravel
db_host: 192.168.80.168
db_port: 3306

Sécurisation des permissions

sudo chown -R nicolas:nicolas group_vars

# Sécurisation dossier DB
sudo chmod 700 group_vars/db
sudo chmod 600 group_vars/db/vault.yml

# Sécurisation dossier Web
sudo chmod 700 group_vars/web
sudo chmod 600 group_vars/web/vault.yml

Les fichiers Vault ne sont jamais versionnés ou lus en clair : les permissions Unix restreignent leur accès au seul utilisateur de déploiement.

4. Rôle : Database

roles/database/defaults/main.yml

---
web_server_ip: "192.168.80.167"

roles/database/tasks/main.yml

Installation de MySQL Server, sécurisation initiale (suppression des comptes anonymes et de la base de test), création de la base et d'un utilisateur Laravel dont l'accès est restreint à l'IP du serveur web, puis ouverture du port 3306 sur Firewalld.

---
- name: Installer MySQL server, client et PyMySQL
  dnf:
    name:
      - mysql-server
      - mysql
      - python3-PyMySQL
    state: present

- name: Activer et démarrer MySQL
  systemd:
    name: mysqld
    state: started
    enabled: yes

- name: Définir le mot de passe root MySQL
  mysql_user:
    login_user: root
    login_password: ""
    user: root
    password: "{{ mysql_root_password }}"
    host_all: yes
    check_implicit_admin: yes
  ignore_errors: yes

- name: Supprimer les utilisateurs anonymes
  mysql_user:
    login_user: root
    login_password: "{{ mysql_root_password }}"
    name: ''
    host_all: yes
    state: absent

- name: Supprimer la base de test
  mysql_db:
    login_user: root
    login_password: "{{ mysql_root_password }}"
    name: test
    state: absent

- name: Créer la base Laravel
  mysql_db:
    login_user: root
    login_password: "{{ mysql_root_password }}"
    name: "{{ laravel_db }}"
    state: present
    encoding: utf8mb4
    collation: utf8mb4_unicode_ci

- name: Créer l'utilisateur Laravel (Autorisé depuis le serveur Web)
  mysql_user:
    login_user: root
    login_password: "{{ mysql_root_password }}"
    name: "{{ laravel_user }}"
    password: "{{ laravel_password }}"
    host: "{{ web_server_ip }}"
    priv: "{{ laravel_db }}.*:ALL"
    state: present

- name: Ouvrir le port MySQL (Firewall)
  firewalld:
    port: 3306/tcp
    permanent: yes
    state: enabled

- name: Recharger firewalld
  systemd:
    name: firewalld
    state: restarted

5. Rôle : PHP

roles/php/tasks/main.yml

Activation du dépôt REMI et du module PHP 8.3, puis installation de PHP et des extensions requises par Laravel (mysqlnd, xml, mbstring, curl, opcache...).

---
- name: Installer dnf-plugins-core
  dnf:
    name: dnf-plugins-core
    state: present

- name: Installer EPEL Release
  dnf:
    name: https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm
    state: present
    disable_gpg_check: yes

- name: Activer repo REMI et module PHP 8.3
  shell: |
    dnf install -y https://rpms.remirepo.net/enterprise/remi-release-9.rpm
    dnf module reset php -y
    dnf module enable php:remi-8.3 -y
  args:
    creates: /etc/yum.repos.d/remi.repo

- name: Installer PHP et extensions
  dnf:
    name:
      - php
      - php-cli
      - php-common
      - php-fpm
      - php-mysqlnd
      - php-xml
      - php-json
      - php-zip
      - php-gd
      - php-mbstring
      - php-curl
      - php-opcache
      - git
      - unzip
      - curl
    state: present

6. Rôle : Apache

roles/apache/tasks/main.yml

---
- name: Installer Apache
  dnf:
    name: httpd
    state: present

- name: Démarrer Apache
  systemd:
    name: httpd
    enabled: yes
    state: started

- name: Déployer VirtualHost Laravel
  template:
    src: laravel.conf.j2
    dest: /etc/httpd/conf.d/laravel.conf
  notify: Restart Apache

roles/apache/handlers/main.yml

---
- name: Restart Apache
  systemd:
    name: httpd
    state: restarted

roles/apache/templates/laravel.conf.j2

<VirtualHost *:80>
    DocumentRoot {{ app_path }}/public

    <Directory {{ app_path }}/public>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog /var/log/httpd/laravel_error.log
    CustomLog /var/log/httpd/laravel_access.log combined
</VirtualHost>

8. Rôle : Laravel

roles/laravel/tasks/main.yml

Installation de Laravel via Composer, attribution des permissions Apache, droits d'écriture sur storage et cache, génération de la clé applicative, configuration du .env et exécution des migrations en contexte apache.

---
- name: Créer dossier application
  file:
    path: "{{ app_path }}"
    state: directory
    mode: "0755"

- name: Installer Laravel
  command: /usr/local/bin/composer create-project laravel/laravel .
  args:
    chdir: "{{ app_path }}"
    creates: "{{ app_path }}/artisan"

- name: Permissions Apache
  file:
    path: "{{ app_path }}"
    recurse: yes
    owner: apache
    group: apache

- name: Droits écriture storage/cache
  file:
    path: "{{ item }}"
    recurse: yes
    mode: "0775"
  loop:
    - "{{ app_path }}/storage"
    - "{{ app_path }}/bootstrap/cache"

- name: Générer clé Laravel
  command: sudo -u apache php artisan key:generate
  args:
    chdir: "{{ app_path }}"

- name: Configurer .env
  lineinfile:
    path: "{{ app_path }}/.env"
    regexp: "{{ item.regexp }}"
    line: "{{ item.line }}"
  loop:
    - { regexp: '^DB_CONNECTION=', line: 'DB_CONNECTION=mysql' }
    - { regexp: '^DB_HOST=',       line: 'DB_HOST={{ db_host }}' }
    - { regexp: '^DB_PORT=',       line: 'DB_PORT={{ db_port }}' }
    - { regexp: '^DB_DATABASE=',   line: 'DB_DATABASE={{ db_name }}' }
    - { regexp: '^DB_USERNAME=',   line: 'DB_USERNAME={{ db_user }}' }
    - { regexp: '^DB_PASSWORD=',   line: 'DB_PASSWORD={{ db_password }}' }

- name: Exécuter migrations
  command: sudo -u apache php artisan migrate --force
  args:
    chdir: "{{ app_path }}"

9. Rôles : sécurité (SELinux & Firewall)

roles/selinux/tasks/main.yml

---
- name: Autoriser connexion réseau Apache
  command: setsebool -P httpd_can_network_connect on

- name: Appliquer contexte SELinux
  command: chcon -R -t httpd_sys_rw_content_t {{ item }}
  loop:
    - "{{ app_path }}/storage"
    - "{{ app_path }}/bootstrap/cache"
    - "{{ app_path }}/.env"

roles/firewall/tasks/main.yml

---
- name: Ouvrir ports HTTP/HTTPS
  firewalld:
    port: "{{ item }}/tcp"
    permanent: yes
    state: enabled
  loop: [80, 443]
