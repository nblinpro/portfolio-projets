Déploiement d'une Infrastructure Critique Haute Disponibilité

Migration d'une PME vers une infrastructure de virtualisation open-source moderne basée sur Proxmox VE. Mise en place d'un cluster 3 nœuds HA avec segmentation réseau par VLANs, stockage distribué Ceph, pare-feu OPNsense, serveur web HA et monitoring centralisé — le tout automatisé via Ansible et Terraform.

  • Cluster Proxmox 3 nœuds HA (pve-01/02/03) — Live migration, fencing STONITH, quorum automatique
  • Segmentation réseau 3 VLANs (Management · DMZ · LAN Interne) — pare-feu OPNsense/pfSense
  • Stockage distribué Ceph + ZFS/iSCSI + NFS — réplication multi-nœuds, snapshot automatique
  • Nginx HA Cluster + Load Balancer, LXC base de données, monitoring Zabbix + Prometheus/Grafana
  • Automatisation complète : Ansible, Terraform, Cloud-Init, GitLab-Runner CI/CD

RapidSoft — Pipeline CI/CD Sécurisé

Sécurisation du SDLC d'un éditeur de logiciels bancaires via deux missions complémentaires — patch management automatisé des dépendances (Renovate + Trivy) et conformité des pipelines GitLab (Plumber).   • Mission 1 — Benchmark 7 outils SCA, architecture Renovate + Trivy + Dependency-Track
