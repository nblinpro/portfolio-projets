Déploiement automatisé Samba via Ansible

Automatisation d'un serveur de fichiers collaboratif sécurisé — gestion des utilisateurs, groupes, permissions SetGID et secrets via Ansible Vault.

Contexte

Architecture du projet

Stack technique

  • Samba (CIFS/SMB) — partage réseau
  • Gestion des groupes Linux (partageurs)
  • Utilisateurs sans login shell
  • Permissions SetGID (2770) sur le partage
  • Configuration smb.conf via blockinfile
  • Handler de redémarrage du service

Sécurité & secrets

  • Ansible Vault pour les mots de passe Samba
  • Permissions 700/600 sur group_vars/samba
  • Utilisateur test sans accès shell
  • Accès restreint aux membres du groupe
  • no_log: true sur les tâches de mot de passe
Ansible Samba Vault Ubuntu

1. Arborescence du projet

mon_projet_ansible/
├── group_vars/
│   └── samba/
│       └── vault.yml            # Secrets chiffrés
├── hosts.ini                    # Inventaire
├── roles/
│   └── samba/
│       ├── defaults/main.yml    # Variables par défaut
│       ├── handlers/main.yml    # Restart service
│       └── tasks/main.yml       # Tâches principales
└── samba.yml                    # Playbook principal

2. Configuration racine

Fichier d'inventaire — hosts.ini

[samba]
srv_samba ansible_host=@IP_Machine ansible_user=user

Playbook principal — samba.yml

---
- name: Configuration du Serveur de Fichiers (Samba)
  hosts: samba
  become: yes
  vars_files:
    - group_vars/samba/vault.yml
  roles:
    - samba

3. Variables & sécurité (Vault)

Création du coffre-fort Ansible Vault

ansible-vault create group_vars/samba/vault.yml

Contenu du vault — group_vars/samba/vault.yml

vault_samba_pass_test: "test"
vault_samba_pass_admin: "user"

Sécurisation des permissions du dossier de secrets après création du vault :

sudo chown -R nicolas:nicolas group_vars

sudo chmod 700 group_vars/samba
sudo chmod 600 group_vars/samba/vault.yml

4. Rôle Ansible : samba

roles/samba/defaults/main.yml

---
samba_share_path: "/srv/partage_commun"
samba_group_name: "partageurs"
samba_user_test: "test"
samba_admin_user: "user"

roles/samba/handlers/main.yml

---
- name: Restart Samba
  ansible.builtin.service:
    name: smbd
    state: restarted

roles/samba/tasks/main.yml

---
- name: Installer Samba
  ansible.builtin.apt:
    name: samba
    state: present
    update_cache: yes

- name: Créer le groupe de partage "{{ samba_group_name }}"
  ansible.builtin.group:
    name: "{{ samba_group_name }}"
    state: present

- name: Créer l'utilisateur test (sans login)
  ansible.builtin.user:
    name: "{{ samba_user_test }}"
    shell: /usr/sbin/nologin
    create_home: no
    groups: "{{ samba_group_name }}"
    append: yes
    state: present

- name: Ajouter l'admin "{{ samba_admin_user }}" au groupe
  ansible.builtin.user:
    name: "{{ samba_admin_user }}"
    groups: "{{ samba_group_name }}"
    append: yes

- name: Configurer le dossier partagé (Permissions 2770)
  ansible.builtin.file:
    path: "{{ samba_share_path }}"
    state: directory
    owner: root
    group: "{{ samba_group_name }}"
    mode: '2770'

- name: Définir le mot de passe Samba pour test
  ansible.builtin.shell: >
    (echo '{{ vault_samba_pass_test }}'; echo '{{ vault_samba_pass_test }}') | smbpasswd -s -a {{ samba_user_test }}
  register: smb_test_result
  changed_when: "'Added user' in smb_test_result.stdout"
  no_log: true

- name: Définir le mot de passe Samba pour l'Admin
  ansible.builtin.shell: >
    (echo '{{ vault_samba_pass_admin }}'; echo '{{ vault_samba_pass_admin }}') | smbpasswd -s -a {{ samba_admin_user }}
  register: smb_admin_result
  changed_when: "'Added user' in smb_admin_result.stdout"
  no_log: true

- name: Configurer le partage dans /etc/samba/smb.conf
  ansible.builtin.blockinfile:
    path: /etc/samba/smb.conf
    marker: "# {mark} ANSIBLE MANAGED BLOCK - PARTAGE COMMUN"
    block: |
      [DossierCommun]
          comment = Partage pour test et moi
          path = {{ samba_share_path }}
          browsable = yes
          read only = no
          guest ok = no
          valid users = @{{ samba_group_name }}
          create mask = 0660
          directory mask = 0770
          force group = {{ samba_group_name }}
  notify: Restart Samba

- name: Afficher les informations de connexion
  ansible.builtin.debug:
    msg:
      - "Installation terminée avec succès !"
      - "Windows : \\\\{{ ansible_host }}\\DossierCommun"
      - "Linux   : smb://{{ ansible_host }}/DossierCommun"
