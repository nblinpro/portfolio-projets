Déploiement & Orchestration OpenStack

Déploiement complet d'un cloud privé OpenStack via DevStack sur Ubuntu 24.04 — Nova, Neutron, Swift, Cinder, Keystone.

Contexte

Architecture Cloud Privé

OpenStack est la plateforme IaaS open-source leader pour les clouds privés et hybrides. Ce projet académique (Ynov Campus, Mastère M1) consiste à déployer et maîtriser un cloud complet avec toutes ses composantes.

DevStack permet un déploiement all-in-one sur une machine Ubuntu, idéal pour l'apprentissage et le lab. Chaque service est configuré, testé et documenté dans des TPs dédiés.

OpenStack DevStack Ubuntu 24.04 Cloud IaaS Python
# DevStack Installation
git clone https://opendev.org/openstack/devstack
cd devstack

# local.conf configuration
[[local|localrc]]
HOST_IP=192.168.1.100
ADMIN_PASSWORD=SecurePass123
DATABASE_PASSWORD=$ADMIN_PASSWORD
RABBIT_PASSWORD=$ADMIN_PASSWORD
SERVICE_PASSWORD=$ADMIN_PASSWORD

# Enable services
enable_service nova neutron swift
enable_service cinder keystone glance

# Deploy
./stack.sh
Services

Services OpenStack

Chaque service a été déployé, configuré et testé avec une documentation complète.

Keystone

Identity Service — service d'authentification et d'autorisation : gestion des utilisateurs, projets, rôles et tokens. Endpoint catalogue pour tous les services.

Tokens RBAC API

Nova

Compute Service — gestion des instances de calcul (VMs). Création, démarrage, arrêt et migration de machines virtuelles. Gestion des flavors et quotas.

Instances Flavors KVM

Neutron

Network Service — service réseau : création de réseaux virtuels, sous-réseaux, routeurs, security groups et floating IPs. SDN cloud.

SDN OVS Floating IP

Glance

Image Service — catalogue et stockage des images de systèmes d'exploitation. Import d'images Ubuntu, Debian, CentOS au format QCOW2.

Images QCOW2 Catalogue

Cinder

Block Storage — stockage bloc persistant : création de volumes, snapshots et attachement à des instances Nova. Équivalent des disques EBS.

Volumes Snapshots LVM

Swift

Object Storage — stockage objet distribué et résilient : containers et objets, API compatible S3. Idéal pour les sauvegardes et médias.

S3 Containers API REST
