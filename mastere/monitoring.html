Monitoring Prometheus & Grafana

Documentation technique du déploiement IaC pour la surveillance des services critiques — provisioning automatisé, stack Prometheus / Grafana / cAdvisor, configuration du scrape.

Architecture

Architecture du stack de supervision

Une VM dédiée, provisionnée par Ansible, exécute la stack de monitoring en Docker Compose. Prometheus scrape les métriques exposées par cAdvisor (conteneurs) et node_exporter (hôtes), Grafana consomme Prometheus comme datasource.

VM Monitoring

Docker Compose orchestrant Prometheus (:9090), Grafana (:3000) et cAdvisor (:8080), provisionnés via Ansible (install_base.yaml : Docker CE + open-vm-tools).

Hôtes supervisés

Host 1 — 192.168.80.151 : node_exporter :9100 + apache_exporter :9117. Host 2 — 192.168.80.152 : node_exporter :9100.

Flux de scrape

Prometheus interroge cAdvisor (:8080), node_exporter (:9100) local et distant, et apache_exporter (:9117) sur Host 1. Grafana lit Prometheus comme datasource et l'utilisateur accède à Grafana en HTTP :3000.

Étape 1

Provisioning automatisé (Ansible)

Un playbook unique (install_base.yaml) prépare la VM cible : mise à jour APT, installation d'open-vm-tools, ajout du dépôt officiel Docker et installation de docker-ce.

nicolas@promfana:~/ansible

---
- name: Installation Docker et Open VM Tools sur la machine locale
  hosts: localhost
  connection: local
  become: yes

  tasks:

    - name: Mettre à jour l'APT
      apt:
        update_cache: yes

    - name: Installer open-vm-tools
      apt:
        name: open-vm-tools
        state: present

    - name: Installer dépendances pour Docker
      apt:
        name:
          - ca-certificates
          - curl
          - gnupg
        state: present

    - name: Ajouter la clé GPG Docker
      apt_key:
        url: https://download.docker.com/linux/ubuntu/gpg
        state: present

    - name: Ajouter le dépôt Docker
      apt_repository:
        repo: "deb [arch=amd64] https://download.docker.com/linux/ubuntu {{ ansible_distribution_release }} stable"
        state: present

    - name: Mise à jour APT après ajout dépôt Docker
      apt:
        update_cache: yes

    - name: Installer docker-ce
      apt:
        name: docker-ce
        state: present

    - name: S'assurer que Docker démarre
      service:
        name: docker
        enabled: yes
        state: started
Étape 2

Stack de monitoring (Docker Compose)

Quatre services conteneurisés partagent un réseau bridge dédié : prometheus, grafana, cadvisor et nodeexporter (en network_mode host pour accéder aux métriques système).

nicolas@promfana:~/monitoring

version: "3.8"

services:
  prometheus:
    image: prom/prometheus
    container_name: prometheus
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"
    networks:
      - monitor

  grafana:
    image: grafana/grafana
    container_name: grafana
    ports:
      - "3000:3000"
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
    networks:
      - monitor

  cadvisor:
    image: gcr.io/cadvisor/cadvisor:latest
    container_name: cadvisor
    ports:
      - "8080:8080"
    volumes:
      - /:/rootfs:ro
      - /var/run:/var/run:ro
      - /sys:/sys:ro
      - /var/lib/docker/:/var/lib/docker:ro
    networks:
      - monitor

  nodeexporter:
    image: prom/node-exporter
    container_name: nodeexporter
    ports:
      - 9100:9100
    restart: unless-stopped
    pid: "host"
    network_mode: host
    command:
      - '--path.rootfs=/'

networks:
  monitor:
    driver: bridge
Étape 3

Configuration du scrape (Prometheus)

Intervalle de scrape global à 5 secondes, avec quatre jobs : prometheus (auto-monitoring), cadvisor, nodeexporter (les deux hôtes) et apache-client (apache_exporter sur Host 1).

nicolas@promfana:~/monitoring/prometheus.yml

global:
  scrape_interval: 5s

scrape_configs:
  - job_name: "prometheus"
    static_configs:
      - targets: ["prometheus:9090"]

  - job_name: "cadvisor"
    static_configs:
      - targets: ["cadvisor:8080"]

  - job_name: "nodeexporter"
    static_configs:
      - targets: ["192.168.80.152:9100"]
      - targets: ["192.168.80.151:9100"]

  - job_name: "apache-client"
    static_configs:
      - targets: ["192.168.80.151:9117"]

La configuration expose 4 jobs de scrape distincts couvrant Prometheus lui-même, cAdvisor, node_exporter sur les deux hôtes supervisés et apache_exporter sur Host 1.
